# AI_USAGE.md — AI usage log for the TSS lab deliverable (`lab/`)

Required format per the assignment: **tool · purpose · prompt/request ·
result · author edits · verification/validation**, defensible at presentation.
This file logs every significant use of AI tooling that contributed to the
deliverables in `lab/` (SPEC, the four test suites + derivation docs, the
CFG artifacts, the manual mutants + demo, the two-tool mutation analysis, and the Word/PDF documentation and slide deck).

**Honest scope statement.** This lab was produced *with* AI coding agents
under the author's direction: a ZCode CLI agent (GLM model) driving the local Python
3.14.6 / pytest 8.4.2 toolchain on Windows (entries 1–12), and Claude Code (Anthropic), which completed Phase 7 and did the 05.11.2026 documentation audit, corrections and re-verification (entries 12–13). The agents ported the module,
wrote the specification and all suites/docs, and executed every verification
run whose receipts are cited below. No other AI tools (ChatGPT, Copilot,
Gemini, …) were used. The author set the scope, reviewed every artifact, and is
responsible for its content — including the parts generated by the agents.
The module under test itself (`pricing.py`) is the author's own pre-existing
code from the `momentstudio` repository, written before this lab; it was
**not** AI-generated for this assignment.
